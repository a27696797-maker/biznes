"Решите: Найти точку максимума функции
y = (x² − 4x + 5) · eˣ"
Давай разберем эту задачу вместе! 🎯

Сначала найдем производную:
y' = (2x − 4) · eˣ + (x² − 4x + 5) · eˣ
y' = eˣ · (2x − 4 + x² − 4x + 5)
y' = eˣ · (x² − 2x + 1)
y' = eˣ · (x − 1)²
Приравняем к нулю:
eˣ · (x − 1)² = 0
Так как eˣ > 0 всегда, то:
(x − 1)² = 0
x = 1
Проверим знак производной:
- При x < 1: y' > 0 (функция растет)
- При x > 1: y' > 0 (функция растет)

⚠️ Внимание! Производная не меняет знак в точке x = 1, значит это точка перегиба, а не экстремум!
